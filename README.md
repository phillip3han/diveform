# DiveForm — 수영 스타트 · 다이빙 폼 분석

브라우저에서만 동작하는 다이빙/수영 스타트 폼 분석 도구입니다. 서버·업로드 없이 영상이 기기 안에서만 처리됩니다.

## 두 가지 분석 모드

| 파일 | 방식 | 필요한 것 | 측정 항목 |
|---|---|---|---|
| `index.html` | **관절 추적** (MediaPipe Pose 33점) | 내장 모델(오프라인 동작) | 뒤무릎·앞무릎·몸통축·이륙각·입수각·정렬편차·DTW |
| `shape.html` | **형태(실루엣) 분석** — 모델 불필요 | 없음 (단일 파일) | 이륙각·입수각·수평속도·비행시간·최고점·몸통축·신전도 |

관절 추적이 어려운 영상(원경·역광·카메라 추적 촬영)에서는 `shape.html`을 쓰세요. 다이버를 박스로 감싸 이륙·정점·입수 3점을 기록하면 탄도 물리로 궤도를 재구성합니다.

## 문서

기획·설계·환경·검증·이력은 [`docs/`](docs/README.md)에 정리되어 있습니다.

## 실행

```bash
python3 -m http.server 8080
# http://localhost:8080/index.html   (관절 추적)
# http://localhost:8080/shape.html   (형태 분석)
```

`index.html`은 같은 폴더의 `vendor/` 를 참조합니다. **파일 하나만 복사하면 엔진이 로드되지 않습니다.** `file://` 로 직접 열면 ES 모듈·WASM 로드가 차단되므로 반드시 서버를 거치세요.

CDN 폴백도 내장되어 있어 `vendor/` 없이도 네트워크가 열려 있으면 동작합니다.

## 기준값 (세계 수준 스타트)

| 항목 | 기준 | 허용 |
|---|---|---|
| 뒤 무릎 (세트) | 80° | 75–85 |
| 앞 무릎 (세트) | 97° | 90–105 |
| 몸통축 (세트) | 32° | 25–40 |
| 이륙각 | 35° | 30–40 |
| 수평속도 | 4.5 m/s | 4.0–5.0 |
| 입수각 | 35° | 30–40 |
| 정렬편차 | 2 cm | 0–5 |

점수 가중치: 수평속도 30 · 입수각 20 · 정렬 20 · 이륙각 15 · DTW 10 · 세트 5.

## 실측 검증

4개 클립(1280×720 / 1920×1080, 10fps 추론) 기준 관절 검출률:

| 클립 | 개선 전 | 고정해상도 크롭 + 연속성 추적 후 |
|---|---|---|
| v1 | 정상 | 100% |
| v2 | 정상 (팔꿈치 33%) | 75% |
| v3 | 13% | 77% |
| v4 | 0% | 47% |

형태 분석의 탄도 수학은 정답을 아는 합성 데이터로 검증했습니다 — 참값 `pxPerM=60 · 35° · 4.5 m/s` → 복원 `60.00 · 35.00° · 4.50 m/s`, 적합오차 `0.00 px`.

## 알려진 한계

- **카메라가 다이버를 따라가는 촬영**은 화면 좌표계에서 포물선이 나타나지 않아 궤도 분석이 왜곡됩니다. 삼각대 고정 · 측면 촬영을 권장합니다.
- 원경(전체 프레임의 5% 미만)에서 관절 검출률이 급격히 떨어집니다.
- `shape.html`의 몸통축은 **실루엣 장축 각도**이며 관절 각도가 아닙니다.
- 손끝 정밀화(Hand Landmarker)는 입수 전후 소수 프레임에만 적용됩니다.

## 개인정보

모든 처리는 브라우저 안에서 이뤄집니다. 영상은 어디에도 업로드되지 않습니다.

## 라이선스

모델 파일은 MediaPipe(Apache-2.0)에서 배포하는 것을 그대로 포함했습니다. 앱 코드의 라이선스는 저장소 소유자가 지정해야 합니다.
