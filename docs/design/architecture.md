# 아키텍처

```
[영상 파일 / 카메라]
      │ (브라우저 안, 업로드 없음)
      ▼
 <video> 디코딩 ── seek ──► canvas (긴 변 ≤1000px)
      │
      ▼
 scanPeople() ×32  전체+타일로 모든 인물 후보 → pickSeed() 숙인 자세 = 다이버
      ▼
 makeTracker().step()  예측 위치 주변 크롭 → MediaPipe Pose (IMAGE 모드)
      │        거리·크기·자세 게이트, 비행 후 놓치면 종료(입수)
      ▼
 extractFrames()  33점 저장 → 결측 보간(≤0.35s) → 급점프 제거 → Savitzky–Golay
      │
      ├─ refineFingertip()  입수 전후 Hand Landmarker로 손끝
      ├─ normalizeDirection()  오른→왼이면 x 반전
      ▼
 buildAnalysis()  COM, 국면, 이륙각(포물선 적합), 입수각, 정렬, DTW, 점수
      ▼
 render()  모션 재구성 / 영상 위 / 영상 배경, 3국면 스트립, 지표 카드
      ▼
 내보내기: JSON(세션), CSV(모션캡처 33점 × 프레임), PNG(스틸)
```

## 핵심 결정
| 결정 | 이유 |
|---|---|
| 전부 브라우저 (MediaPipe WASM) | 개인정보·서버비용 0, 정적 파일 배포 |
| 모델 내장(`vendor/`) + CDN 폴백 | CDN 차단 환경에서 엔진 로드 실패했던 문제 |
| Pose IMAGE 모드 | 크롭마다 다른 이미지 → VIDEO 모드 추적 상태·타임스탬프가 깨짐 (0% 버그 원인) |
| 고정 해상도 크롭(640px) | 원경에서 인물이 작으면 전체 프레임 검출 실패 |
| 다이버 한 명을 씨앗으로 정해 추적 | 프레임별 최선 선택은 옆 사람·다음 선수로 갈아탐 (4개 영상 실측) |
| 자세 게이트(몸통 < 50° 거부) | 카메라 패닝 때문에 위치만으로는 다이버와 옆 사람 구분 불가 |
| 정답 = 국면 × 관절 격자 | 세트와 입수의 최적 자세가 다름 |
| 궤적 비교에 DTW | 선수마다 타이밍이 달라 프레임 i 대 i 비교는 부당 |
| 관절각은 worldLandmarks(3D) 우선 | 사선 뷰에서 2D 각이 13°까지 틀어짐 |
| 영상 대신 좌표만 저장 | 3초 세션 ≈ 29KB |
