# 화면 구성 (index.html)

- **헤더**: 엔진 상태 배지, 영상 업로드 버튼, 데모/영상 분석 모드
- **우측 상단 도크**: 드롭 영역(클릭·드래그), 카메라 촬영(`capture="environment"`), 데모 보기, 상태(업로드→분석 중→완료). 팝업 없음
- **캔버스**: 모션 재구성(기본) / 영상 위 / 영상 배경 토글. 스타트 블록 형상(상판·다리·30° 킥플레이트·그랩바·0.70 m), 수면선, 1 m 스케일, 이상 궤적(점선)·실측 궤적, 최대 이탈 마커(cm / °), 우측 이륙각 비교 배지
- **메타바**: 파일, fps, 스케일, 방향, 추적률(보간 %), 국면
- **재생바**: 재생, ◀ ▶ 프레임 스텝, 0.1×/0.25×/0.5×/1×, 스틸 PNG, 스크럽 + 국면 밴드
- **국면 이동**: ① 점프 대기 ② 이륙 ③ 입수, 점프 구간 재생
- **3국면 스트립**: 대기/이륙/입수 미니 스켈레톤 + 국면별 실측값
- **우측 카드**: 보정선(수면·블록 상면), 진행 단계, 점수, 지표 카드, 교정 포인트, JSON/CSV 내보내기

`shape.html`: 영상 열기 → 다이버 박스 드래그 → 이륙/정점/입수 기록 → 중력으로 px/m 자동 보정, 이륙·입수각, 수평속도, 비행시간, 몸통축(PCA), 신전도.
