# 화면 구성 (index.html)

## 디자인 원칙
- **색**: 수영장 데크 흰색 바탕(`--deck #F3F6F7`), 풀 남색 글자·무대(`--ink #0F2A36`, `--pool #0B2733`),
  조작 요소는 물빛 청록 하나(`--aqua #0E8FA0`). 배영 깃발 노랑(`--flag #F4C542`)은 이상 궤적과 고정된 기록에만
- **숫자**: 점수·지표·기록 점수는 대회 전광판처럼 좁은 장체 숫자(Barlow Condensed). 화면에서 유일하게 튀는 요소
- **글꼴**: 본문 Pretendard (불러오지 못하면 시스템 한글 글꼴)
- 보조 기능은 접는다: 내보내기는 메뉴, 보정선·분석 정보는 '고급 설정', 분석 진행 카드는 분석 중에만
- 국면 색: 세트 `#8A9BA3` · 이륙 `#2BA6B5` · 비행 `#0E7C8C` · 입수·수중 `#9BB8C4`

## 배치
```
DiveForm  수영 스타트 동작 분석                       ● 엔진 상태  [영상 분석하기]
┌──────────── 무대 (캔버스) ────────────┐  ┌ 분석 중 (분석할 때만) ┐
│                                       │  ├ 분석 기록 ───────────┤
├ 파일 · 추적률 · 국면 · 축척 ──────────┤  │ [영상 올리기] [촬영]  │
│ ▶ 재생 ‹ › 0.25×             0.37 s  │  │ 고정됨 ★ …            │
│ ─────────●────────── (국면 띠)        │  │ 최근 분석 n/5 …       │
│ 동작 재구성|영상 위에  표시: …  다이버 지정  내보내기 │ ├ 종합 점수 ──────────┤
└───────────────────────────────────────┘  ├ 지표 (현재 장면) ────┤
장면 요약 (누르면 이동)      점프 구간 재생   ├ 교정 포인트 ─────────┤
[ 대기 | 이륙 | 입수 ]                      └ 고급 설정 (보정선·분석 정보·JSON) ┘
```
휴대폰 폭(≤1120px)에서는 한 줄로 쌓인다.

## 분석 기록
- 분석이 끝나면 **자동 저장** (결과 + 원본 영상, 이 브라우저의 IndexedDB `diveform` — 서버로 보내지 않음)
- **최근 분석**: 고정하지 않은 기록은 새 분석을 저장할 때 최근 5개만 남기고 오래된 것부터 지운다
- **고정(☆→★)**: 고정한 기록은 개수 제한 없이 남고 새 분석에 밀려나지 않는다
- 기록을 누르면 추적을 다시 하지 않고 저장된 관절 좌표로 바로 열린다
- ✎ 이름 바꾸기(선수 이름 등), × 두 번 눌러 삭제
- '다이버 지정'으로 재추적하면 새 기록을 만들지 않고 지금 기록을 덮어쓴다
- 기기·브라우저마다 따로 저장된다 (폰과 Mac의 기록은 공유되지 않음)

## 무대 위 요소
스타트 블록 형상(상판·다리·30° 킥플레이트·그랩바·0.70 m), 수면선, 1 m 축척, 이상 궤적(노란 점선)·실제 궤적(청록),
가장 크게 벗어난 지점(cm / °), 오른쪽 위 이륙각 비교 배지. '다이버 지정'을 누르면 장면 속 사람들에게 번호 박스가 뜬다.

## 측정 조건 안내 (종합 점수 카드)
사선 촬영 정도, 카메라 이동, 이륙각·수평속도 참고값 여부와 이유.

`shape.html`: 영상 열기 → 다이버 박스 드래그 → 이륙/정점/입수 기록 → 중력으로 px/m 자동 보정.
