# 포즈 처리 파이프라인

## 1. 엔진
- `vendor/vision_bundle.mjs` (@mediapipe/tasks-vision 0.10.14), `pose_landmarker_full.task`, `hand_landmarker.task`
- GPU 위임 실패 시 CPU. Pose는 `runningMode:"IMAGE"`, `numPoses:4`

## 2. 다이버 추적 (extractFrames)
실제 영상은 측면이 아니라 풀 끝에서 비스듬히 찍히고, 카메라가 다이버를 따라 움직이며, 바로 옆에 다른 사람이 서 있는 경우가 많다.
"프레임마다 가장 그럴듯한 사람"을 고르면 옆 사람·다음 선수로 갈아탄다. 그래서 다이버 한 명을 정해 끝까지 따라간다.

1. **1차 스캔** — 영상 전체에서 32장. 각 장을 전체 화면 + 겹치는 타일 6개로 추론해 모든 인물 후보를 모은다 (같은 사람은 몸통 중심 거리 < 0.5 몸통으로 병합)
2. **씨앗** — 영상 앞 40%에서 몸통을 55° 넘게 숙인 자세로 가장 오래 머문 무리 = 다이버. 서 있는 사람(몸통 수직)은 제외된다
3. **조밀 추적** — 씨앗 시각부터 길이×60 샘플(40~240). 매 프레임 직전 위치+속도로 예측한 지점 주변을 패딩 2.2 → 3.6 → 6.0배 → 전체 순으로 탐색
   - 거리 게이트: min(4.5, 1.2 + 12·dt) 몸통 길이
   - 크기 게이트: 몸통 길이 비율 0.4~2.5 (최근 7개 중앙값 기준)
   - **자세 게이트: 몸통 기울기 < 50°(선 사람)는 거부** — 준비~입수 동안 다이버는 항상 숙이거나 수평
   - 비용 = 거리/게이트 + |log 크기비| − 0.5·가시도
4. **종료** — 비행 자세(몸통 > 60° 그리고 골반→발목 > 50°)이거나 준비 위치에서 3몸통 이상 벗어난 뒤 0.4초 놓치면 입수로 보고 추적 종료. 이후 다른 사람으로 갈아타지 않는다
5. 너무 꽉 자른 크롭은 모델이 엉뚱한 큰 골격을 만들어 내므로 최소 패딩 2.2배를 둔다

추적기는 국면 힌트도 넘긴다: `flightIdx`(비행 자세가 처음 잡힌 프레임), `lastIdx`(입수로 추적 종료), `seedIdx`.

## 3. 영상 디코딩 확인
- 파일 앞뒤 바이트에서 `hvc1`/`hev1`(HEVC), `avc1`(H.264)을 찾아 코덱 추정
- 메타데이터 로드 실패 또는 첫 프레임이 검으면 코덱 원인과 해결책(Safari/Chrome, 아이폰 '높은 호환성', H.264 변환)을 표시

## 4. 관절 매핑 (Pose 33점)
| 앱 키 | 랜드마크 |
|---|---|
| f1 / f2 발끝 | 31 / 32 |
| a1 / a2 발목 | 27 / 28 |
| k1 / k2 무릎 | 25 / 26 |
| hip 골반 | 23·24 중점 |
| shoulder 어깨 | 11·12 중점 |
| elbow 팔꿈치 | 13 또는 14 (카메라 쪽) |
| hand 손 | 15 또는 16 (카메라 쪽) → 입수 구간 Hand 21점의 12(중지 끝) |
| head | 0 |

`1` = 카메라 쪽 다리, `2` = 반대쪽. 좌/우 세트(어깨·골반·무릎·발목·발끝) visibility 합이 큰 쪽을 카메라 쪽으로 본다 (`toPose`).
보조: 발뒤꿈치 29·30 (블록 접촉 판정)

## 5. 후처리
- 결측: 앞뒤 정상 프레임 간격 < 0.35s일 때만 선형 보간 (`interp` 표시)
- 급점프: 인접 프레임 정규좌표 이동 > 0.22면 중간값으로 (`fixed`)
- Savitzky–Golay 창 5, 2차
- 실제 검출 프레임 < 12개면 실패 처리. 추적률은 준비~입수 구간 기준으로 표시

## 6. 분석 (buildAnalysis)
- 방향 정규화, 세트 자세에서 x가 작은 다리 = 뒤발
- COM: 7분절 질량비 (몸통 0.497, 허벅지 0.100, 정강이 0.0465, 발 0.0145 …)
- 국면: 출발(누적 변위 > 몸높이 1.2%) → 이륙(추적기 `flightIdx` 우선, 없으면 양발이 블록 상면에서 5cm 이탈 4프레임) → 정점 → 입수(추적기 `lastIdx` 우선, 없으면 손끝 수면 통과)
- 이륙각: 비행 구간 COM에 포물선 최소자승 적합 → 이륙 순간 vx, vy
- 스케일: 블록 상면~수면 = 0.70 m (보정선 드래그로 조정)
