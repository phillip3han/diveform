# 포즈 처리 파이프라인

## 1. 엔진
- `vendor/vision_bundle.mjs` (@mediapipe/tasks-vision 0.10.14), `pose_landmarker_full.task`, `hand_landmarker.task`
- GPU 위임 실패 시 CPU. Pose는 `runningMode:"IMAGE"`, `numPoses:4`

## 2. 프레임 샘플링
- 길이 × 60 샘플, 40~240 사이. 각 샘플 `seekTo` 후 canvas에 그림

## 3. detectBest (프레임당)
1. 직전 bbox 주변 패딩 0.5 / 0.9 / 1.6배 크롭 (점수 > 0.35면 종료)
2. 전체 프레임, 중앙 크롭 (점수 > 0.06이면 종료)
3. 3×3 타일 (원경 최후 수단)
- 모든 크롭은 긴 변 640px로 리사이즈해 추론, 결과는 원본 좌표로 역변환
- 점수 = 평균 visibility × 가로 점유율, 직전 위치가 있으면 거리 가중 45%

## 4. 관절 매핑 (Pose 33점)
| 앱 키 | 랜드마크 |
|---|---|
| f1 / f2 발끝 | 31 / 32 |
| a1 / a2 발목 | 27 / 28 |
| k1 / k2 무릎 | 25 / 26 |
| hip 골반 | 23·24 중점 |
| shoulder 어깨 | 11·12 중점 |
| elbow 팔꿈치 | 13 또는 14 (카메라 쪽) |
| hand 손 | 15 또는 16 (카메라 쪽) → 입수 구간 Hand 21점의 12(중지 끝) |
| head | 0 |

`1` = 카메라 쪽 다리, `2` = 반대쪽. 좌/우 세트(어깨·골반·무릎·발목·발끝) visibility 합이 큰 쪽을 카메라 쪽으로 본다 (`toPose`).
보조: 발뒤꿈치 29·30 (블록 접촉 판정)

## 5. 후처리
- 결측: 앞뒤 정상 프레임 간격 < 0.35s일 때만 선형 보간 (`interp` 표시)
- 급점프: 인접 프레임 정규좌표 이동 > 0.22면 중간값으로 (`fixed`)
- Savitzky–Golay 창 5, 2차
- 실제 검출 프레임 < 25%면 실패 처리

## 6. 분석 (buildAnalysis)
- 방향 정규화, 세트 자세에서 x가 작은 다리 = 뒤발
- COM: 7분절 질량비 (몸통 0.497, 허벅지 0.100, 정강이 0.0465, 발 0.0145 …)
- 국면: 출발(누적 변위 > 몸높이 1.2%) → 이륙(양발이 블록 상면에서 5cm 이탈, 4프레임 지속) → 정점 → 입수(손끝 수면 통과)
- 이륙각: 비행 구간 COM에 포물선 최소자승 적합 → 이륙 순간 vx, vy
- 스케일: 블록 상면~수면 = 0.70 m (보정선 드래그로 조정)
