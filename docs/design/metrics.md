# 지표와 기준값

## 각도 정의 (서로 다름 — 섞지 말 것)
| 지표 | 정의 | 계산 |
|---|---|---|
| 뒤 무릎 내각 | 골반–무릎–발목 내각, 세트 자세 | 3D(worldLandmarks), 없으면 2D |
| 몸통축 | 어깨 중점–골반 중점 선이 **수평면**과 이루는 각 (0~90°), 세트 자세 구간 중앙값 | 3D 수평면(XZ) 기준. 카메라가 비스듬해도 기울기는 보존 |
| 이륙각 | 무게중심 속도벡터가 수평면과 이루는 각 | 카메라 이동을 뺀 골반 중점 궤적(실측 프레임)에 포물선 적합, 이상점 제거 후 재적합 |
| 입수각 | 손목 중점–어깨 중점 축이 수면(수평면)과 이루는 각 (0~90°), 입수 직전 3D 프레임 중앙값 | 3D, 없으면 2D(0~90°) |
| 정렬 편차 | 손끝–어깨–힙–발끝 4점 최소자승 직선에서의 최대 이탈 | 2D px ÷ 축척 |

국면: 세트 = 이륙 직전 마지막 준비 자세(몸통 > 55°, 다리 < 40°). 이륙 = 입수 전 마지막으로 다리(골반→발목) < 40°였던 다음 프레임. 입수 = 추적 종료.

예전 2D `atan2`(0~180°)는 다이버가 화면 왼쪽을 향하면 24°를 156°로 냈다 → 모두 0~90° 수평 기준으로 통일.

## 축척과 신뢰도
- **축척(px/m)**: 다이버 몸으로 잡는다. 약원근 투영에서 |화면 분절 px| ≈ s·|3D 분절의 (X,Y)| → 8개 분절 비율의 중앙값. 보정선(블록 0.70 m)을 직접 움직이면 그 기준으로 바뀐다
- **카메라 이동**: 다이버를 가린 배경을 160px 흑백으로 이전 프레임과 블록 매칭(2단계 SAD) → 누적 이동을 궤적에서 뺀다
- **신뢰도 게이트**: 보정 궤적에 2차식을 자유 적합해 역산한 중력가속도가 9.81 ± 3.5 m/s²이고 비행 프레임이 7개 이상일 때만 이륙각·수평속도를 점수에 넣는다. 아니면 "참고값"으로 표시
- **사선 경고**: 준비 자세에서 어깨·골반 폭으로 추정한 몸의 비스듬한 정도가 30° 넘으면 "수평속도가 실제보다 작게 나올 수 있음" 안내 (사선 단축은 3D 깊이 추정이 납작해 보정하지 않음)
