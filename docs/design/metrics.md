# 지표와 기준값

## 각도 정의 (서로 다름 — 섞지 말 것)
| 지표 | 정의 |
|---|---|
| 뒤 무릎 내각 | 골반–무릎–발목(발끝) 내각, 세트 자세 |
| 이륙각 | 무게중심 속도벡터가 수평면과 이루는 각 |
| 입수각 | 손끝–어깨 신체축이 수면과 이루는 각 |
| 정렬 편차 | 손끝–어깨–힙–발끝 4점 최소자승 직선에서의 최대 이탈 |
