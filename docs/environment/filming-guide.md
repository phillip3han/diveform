# 촬영 가이드

정확도는 알고리즘보다 촬영 조건이 더 크게 좌우한다.

| 조건 | 권장 | 이유 |
|---|---|---|
| 방향 | 완전 측면 90° | 사선이면 모든 각도가 같은 양만큼 틀어짐 |
| 카메라 | 삼각대 고정, 패닝·줌 금지 | 카메라가 따라가면 화면에 포물선이 안 나와 궤적 분석 불가 |
| 프레이밍 | 블록과 수면이 함께, 입수 지점까지 | 스케일(0.70 m) 계산과 입수 검출 |
| 거리 | 5–8 m, 선수가 화면 높이의 1/3 이상 | 원경이면 검출률 급락 (v4: 47%) |
| 프레임 | 120 fps 권장, 최소 60 | 30 fps면 이륙각 ±6° |
| 기타 | 다른 사람이 앞을 가리지 않게, 역광 피하기 | |
| 포맷 | 아이폰은 "높은 호환성"(H.264) 권장 | HEVC 미지원 브라우저 대응 |
