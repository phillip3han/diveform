# 제품 개요

## 한 줄
수영 스타트 다이빙 영상을 올리면, 그 사람이 어떤 각도로 뛰었는지와 세계 수준의 이상 각도와의 차이를 보여주는 앱.

## 사용자
- 수영 코치: 현장에서 휴대폰으로 찍어 바로 선수에게 보여줌
- 선수·학부모: 가지고 있는 영상을 올려 스타트 폼 확인

## 핵심 시나리오
1. 현장 촬영(카메라 버튼) 또는 보관 영상 업로드
2. 브라우저 안에서 관절 자동 인식: 발끝·발목·무릎·골반·어깨·팔꿈치·손(끝)
3. 점프 대기 → 이륙 → 입수 동작을 스켈레톤으로 재구성해 재생 (정지·프레임 스텝·슬로우)
4. 이상 궤적(이륙 35°, 4.5 m/s)과 실제 궤적을 겹쳐 차이를 각도(°)와 거리(cm)로 표시
5. 국면별 지표와 교정 포인트 3개, 점수

## 원칙
- 영상은 기기 밖으로 나가지 않는다 (서버 없음, 좌표만 저장)
- 숫자는 랩 계측의 대체물이 아니다. 단안 2D 영상은 ±3~5° 오차 → 구간 표기, 저신뢰 프레임은 회색 처리
- 관절 추적이 안 되는 영상에도 결과가 나와야 한다 → `shape.html` 수동 3점 모드

## 범위 밖 (지금은)
로그인, 결제, 서버 저장, 2카메라 3D, 수중 구간 각도(굴절)
