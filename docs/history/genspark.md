# Genspark 개발 이력 (~2026-11-16)

1. 문헌 조사: 세트 뒤 무릎 75–85°, 이륙 30–40°, 입수 ≈35°, 뒤발 수평 임펄스 ≈59%
2. 3국면 스틱피겨 도해
3. 청사진(16섹션) + 합성 스켈레톤 프로토타입
4. MediaPipe 실연동 앱 → 모션 재구성 뷰, 3국면 스트립
5. 업로드 진입점 전면화, 방향 자동 정규화, 정지·슬로우, 스타트 블록 형상, 영상 배경, 이륙각 편차 배지
6. 4개 영상 오프라인(Python) 실측 → 다중 스케일 크롭·ROI 추적 (v3 13→77%, v4 0→47%)
7. CDN 차단 대응 모델 내장(vendor/)
8. 사용자 보고 "전혀 추적 못 함" → 반환 형식 버그 수정했다고 보고했으나 브라우저 미검증
9. 형태(실루엣) 분석 도구 `shape.html` 추가
10. 푸시 준비된 git 저장소(5f28983) zip 전달, GitHub 푸시는 못 함

## 인수 시 발견한 사실
- Genspark는 브라우저에서 실제 영상을 한 번도 끝까지 돌리지 못했다 (Python MediaPipe로만 검출률 측정)
- 브라우저에서 0%가 난 진짜 원인은 타임스탬프 재사용 (changelog 참고)
- "카메라 패닝 때문에 자동 추적 불가"라는 결론은 0% 버그 상태에서 내려진 것이라 재검증 필요
